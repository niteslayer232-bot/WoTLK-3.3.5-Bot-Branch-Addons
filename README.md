# WotLK 3.3.5a Addon Collection (Bot-Compatible)

This repository contains verified working addons for our WotLK 3.3.5a server, including specialized modules for managing companion bots.

## How to Install the Whole Pack (Easiest)
1. Click the green **Code** button at the top right of this page.
2. Click **Download ZIP**.
3. Extract the ZIP file.
4. Copy the folders inside directly into your game directory: `World of Warcraft/Interface/AddOns/`
